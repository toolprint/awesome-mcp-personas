# Claude Code Assistant 🤖💻

*An intelligent development companion that combines visual context, automated workflows, and comprehensive tooling for enhanced Claude Code development productivity.*

## 🎯 Purpose

The Claude Code Assistant persona transforms Claude into a sophisticated development companion by leveraging a carefully orchestrated set of MCP servers. This persona excels at understanding visual development context through screenshots, orchestrating complex development workflows, and providing intelligent assistance across the entire software development lifecycle.

## 👥 Target Audience

- **Claude Code Power Users**: Developers who want to maximize Claude's development assistance capabilities
- **Full-Stack Developers**: Engineers working across frontend, backend, and deployment workflows
- **DevOps Engineers**: Teams managing CI/CD, containerization, and deployment automation
- **Project Managers**: Individuals coordinating development tasks and workflow orchestration
- **Quality Engineers**: Professionals focused on testing, documentation, and code quality

## 🔧 MCP Servers

This persona integrates 10 specialized MCP servers for maximum development capability:

### Core Development
- **everything**: Universal development toolkit and operations
- **git**: Version control operations and repository management
- **docker**: Container management and deployment workflows

### Intelligence & Planning  
- **task-master**: Project planning and workflow orchestration
- **sequential-thinking**: Structured reasoning for complex development problems
- **context7**: Documentation lookup and development pattern matching

### Automation & Monitoring
- **mcping**: Smart notifications and task readiness alerts
- **playwright**: Browser automation, testing, and screenshot capture

### Research & Documentation
- **exa**: Advanced search for development research and solutions
- **markitdown**: Document conversion and content processing
